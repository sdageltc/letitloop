# LetItLoop Ecosystem Community & Discussions Guide

Welcome to the LetItLoop community! We organize open discussions, adapter proposals, and durability findings across our GitHub ecosystem.

## Central Hub & Discussion Categories
All ecosystem discussions are centralized at [github.com/sdageltc/letitloop/discussions](https://github.com/sdageltc/letitloop/discussions):

1. **📢 Announcements**: Release notes, benchmark updates, and ecosystem milestones.
2. **💡 Feature Ideas & RFCs**: Proposals for new durability primitives, AST splices, and recovery mechanics.
3. **🔌 Framework Adapters**: Showcase and discuss custom adapters for new AI agent frameworks (LangGraph, AutoGen, CrewAI).
4. **🙌 Show & Tell**: Share real-world crash recovery traces, benchmark runs, and proof-carrying PR implementations.
5. **🐛 Bug & Triage Support**: Discuss reproduction steps before formal issue submission.
