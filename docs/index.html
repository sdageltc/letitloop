Distributed Systems Invariants

Engineered for Host Crashes & OOM Termination

Zero background daemons, zero external databases, and zero lock contention.

DATA INTEGRITY

Torn-Tail Safe WAL v2

Frames are framed with magic header LILWAL02, payload lengths, and CRC32 checksums. If a crash strikes mid-write, valid-prefix truncation discards the uncommitted fragment and recovers cleanly without state corruption.

CONCURRENCY

Auto-Stealing Lock v2

Supervisor locks detect dead PIDs and automatically steal stale lockfiles. A background heartbeat daemon keeps the lock refreshed during long-latency LLM completions to prevent supervisor timeouts.

VERIFIABILITY

Proof-Carrying Receipts

Every completed execution generates an HMAC-SHA256 sealed ProofReceipt recording AST scopes, command exit codes, and test outputs for deterministic verification in CI/CD gates.

GIT ISOLATION

Worktree Mutex

Parallel workers execute in isolated git worktrees serialized via FileLock. Automatic pre-rollback backup refs protect against unrecoverable state loss during branch merges or resets.

COST & LATENCY

Sub-Millisecond Resume

Previously completed steps are fast-forwarded straight from disk in under 1ms, feeding verified variables directly into execution scope without incurring redundant LLM API costs.

CI/CD AUTOMATION

Autonomous GitHub Suite

Drop-in GitHub Action workflows for automated PR remediation, flaky test isolation, dependency vulnerability patching, and cryptographic conformance scoring.

from letitloop import durable, step

@durable(task_id="scientific-pipeline")
def run_pipeline(dataset_path: str):
    # Step 1: Cached to local WAL in 0.3s
    data = step("load_data", lambda: parse_dataset(dataset_path))

    # Step 2: If SIGKILL strikes here, Step 1 is fast-forwarded in 0.94ms
    model = step("train_model", lambda: train_weights(data))

    # Step 3: Seals proof receipt to .bench_wal/proof_receipt.json
    results = step("evaluate", lambda: run_eval(model))
    return results
