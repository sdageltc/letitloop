The 10-Second Quickstart

Turn fragile multi-step LLM scripts into atomic, crash-proof workflows.

from letitloop import durable, step

@durable
def run_scientific_pipeline(dataset):
    with step("clean_data"):
        cleaned = process(dataset)

    with step("llm_feature_engineering"):
        # 💥 Process dies or SIGKILL fires here?
        features = extract_features(cleaned)

    with step("train_model"):
        model = train(features)
        return model

Irreducible Engineering Capabilities

Deterministic verification and durability built with pure Python.

⚡
Sub-Millisecond Local WAL
Single-file append-only Write-Ahead Log with OS Direct I/O fsync. Recovers valid prefixes and truncates torn writes automatically under sudden host crashes.
🛡️
0% Token Waste on Process Death
When a spot instance gets preempted or battery dies, re-invoking the script skips all finished steps in under 1ms instead of re-querying expensive LLM APIs.
🔒
Cryptographic Proof Receipts
Outputs HMAC-SHA256 sealed verification receipts with test exit codes ($LASTEXITCODE == 0) and multi-language AST syntax checks.
📦
Zero-Daemon Architecture
No Docker containers, no Redis queues, no PostgreSQL databases, no Temporal servers. Just pip install letitloop and go.
