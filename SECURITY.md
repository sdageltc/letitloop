# Security Policy

## Supported Versions
Only the latest released minor version receives active security patches.

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| < 0.2.0 | :x:                |

## Reporting a Vulnerability

Please do not report security vulnerabilities via public GitHub issues.

To report a vulnerability:
1. Open a private security advisory on GitHub under the repository's **Security** tab, OR
2. Email the maintainer directly at `sdageltc@users.noreply.github.com` with:
   - Reproduction steps or proof-of-concept
   - Impact assessment
   - Suggested fix (if available)

We acknowledge receipts within 48 hours and provide a fix timeline within 5 business days.
